# Ultimate Project Management Tool (Excel VBA)

This repository contains a complete VBA implementation package for a standalone Excel macro-enabled workbook (`.xlsm`) that provides:

- Structured project/task/people data model with table-driven logic.
- In-workbook owner updates (`MyUpdates`) with change logging.
- Outlook notification emails (preview/send) for tasks needing updates.
- Dynamic Gantt refresh helper and validation/fix tooling.
- One-click PowerPoint status deck export with executive/project/change slides.
- Optional CSV export/import for owner update concurrency support.

See `docs/Workbook-Build-and-Run.md` for setup, named ranges, and macro wiring.
